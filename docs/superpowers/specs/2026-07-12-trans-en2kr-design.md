# Trans-EN2KR 설계 (영문 원문 우선 한국어 번역 변형본)

> 상태: 승인됨 (2026-07-12). Trans-Complex2KR를 기반으로, 고유명사를 **영문판(공식 EN) 기준**으로 최대한 수용한 변형본.

## 0. 목표와 대원칙

Trans-Complex2KR는 "의미=EN, 문체·고유명 한자음=CHT"였고, **세계관·신화 고유명은 한자음, 인물 개인명만 EN**이 원칙이었다. Trans-EN2KR는 이 원칙을 뒤집어 **고유명사 전반을 영문판 기준으로 수용**한다.

- 확정 4대 결정(사용자, 2026-07-12):
  1. **汜 → 루멘 계열 통합** (龍脈과 汜를 모두 Lumen으로 보는 영문판 수용)
  2. **李(Lee) 가문 → 영문판 전면 수용** (준 / 셴 리 / 로댕 가문 / 가주)
  3. **지명·기물 → 전면 영문 수용(공격적)** (서술형·한자음 지명도 EN 개명 채택)
  4. **라틴/외래 신명 → 영문 표기** (乙皇=헬리우스, 太乙=타이양)
- 유지: 캐릭터 voice·문체·존댓말/호칭 매트릭스, 자연스러운 한국어(직역투 지양), 플레이스홀더/태그.
- 브랜딩/의역 고정 유지: 게임 타이틀 **「별노래의 메아리」**, 별노래(Starsong), 메아리(Echo), 意譯 지명(쓰레기산·실크 오아시스·심수·나루 등).

## 3. 변환 실행 방식

### 3-1. 주 엔진 — josa 인식 결정론적 치환 (Python)
- 큐레이션된 치환 맵(§2). **최장 일치 우선**(복합어 먼저: "만도 촉룡 상회" 등은 구성어 치환으로 자연 해결하되, 순서로 보장).
- **josa 자동 교정**: 명사 치환 후 뒤따르는 조사를 신규 명사 종성 기준 재계산.
  - 자음종결→모음종결 (흑룡→밴시): 이/가, 을/를, 은/는, 과/와, 으로/로, 이나/나, 이란/란, 이랑/랑, 아/야, 이에요/예요 등.
  - 모음종결→자음종결 (영기→루미움, 후토→테라는 모음유지) 반대 방향도 처리.
- diff 전건 검수 가능.

### 3-2. 동음이의 위험 처리
- `곤`(곤란·곤경·곤충…) → `쿤`: 「곤」·태공선·AI(하사품) 문맥으로 **제한 치환**. 일괄 금지.
- `주홍`(주홍색), `대황`(약재 大黃) 등 저빈도 충돌은 「」/지명 문맥 확인.
- 인물 `준`은 Complex도 이미 이름을 '준'으로 썼으므로 대부분 무변경(이준→준, 이씨→로댕만 변경).

### 3-3. ⚠️ 汜(영)→루멘 특별 처리
`영`은 영혼·영원·영역·영향 등과 충돌이 커 일괄 치환 **불가**.
- 안전 치환: `영기→루미움`, `영수→루메나이드`, `영정→루메나이트`, 및 시설명(영기 정련소/영수 가공 공장/조가 영기…)의 복합 형태.
- 단독 `영`(汜) 및 모호 라인: **LLM 문맥 판별 패스**(원 Complex의 CHT 대조 방식 대응). grep `영` 후보 라인만 대상. 汜=루멘 vs 靈(영혼 등)=비대상 판별.

## 4. 검증
- 치환 전후 엔트리/토큰 카운트, 잔여 구용어(용맥·흑룡·촉룡·만도·영기·후토·을황·태을·홍루·영해…) **0** 확인(단, 영은 汜만 대상).
- JSON 파싱 유효성, 플레이스홀더/태그 보존(`{0}` `{1}` `@{0}@` `%s` `<color>` `<p>` `#AVATAR#` `「」`).
- 화자별 대사 스팟체크(에다/준/레미/셴 리), josa 자연성.
- glossary/decisions 문서와 translations 일치성 교차 확인.

## 5. 열린/보류
- 무녀 vs 마녀: **무녀 유지**(역할어). 巫塔=무녀의 탑. 필요 시 사후 변경.
- 家主: **가주** 채택(클랜 마스터 병기 안 함).
- build/ 주입은 후속 작업.
