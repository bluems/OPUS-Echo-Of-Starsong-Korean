# OPUS: Echo of Starsong — 한국어 번역 프로젝트

SIGONO의 우주 어드벤처 게임 **《OPUS: Echo of Starsong》**(*별노래의 메아리*, Steam Full Bloom Edition)의 **비공식 한국어 패치**입니다. 이전에 먼저 [노고해주신 분](https://gall.dcinside.com/mgallery/board/view/?id=indiegame&no=195900)이 계시지만, 해당 파일을 더 이상 입수할 수 없어 직접 다시 번역했습니다. <- 비밀번호를 몰라서 헤맸는데 다른 분이 알려주셨네요.. 번역본 차이 정도+수정가능으로 써주시면 감사하겠습니다.

이 게임은 아직 공식 한국어를 지원하지 않습니다. 그래서 직접, 중국어 원작·영어판·일본어판을 함께 대조해 가며 우리말로 옮겼습니다. 이 저장소는 그 번역 결과물과, **"왜 이렇게 옮겼는가"에 대한 기록**을 모아 둔 곳입니다.

> 개발사(SIGONO)는 [Steam 커뮤니티](https://steamcommunity.com/app/1504500/discussions/0/3825287408062401172/?l=koreana)에서 팬 언어 패치를 긍정적으로 허용하고 있습니다. 이 패치는 게임 파일 중 텍스트가 든 파일 하나(`sharedassets2.assets`)만 바꾸며, 게임 자체를 배포하지는 않습니다.

---

## 1. 패치를 적용하는 법 (게임에서 한국어로 즐기기)

개발 지식이 없어도 아래 3단계면 됩니다.

1. **패치 파일 내려받기** — 이 저장소의 [Releases(릴리스)] 페이지에서 최신 `sharedassets2.assets` 파일을 받습니다.
   -  `*-Complex` : 중문/영문/일문 및 공식 자료, 해외 팬덤 자료 교차 검증한 번역본
   -  `*-EN` : `Complex` 버전과 추출한 인게임 용어집+대사집을 기반으로 영문만 참조 또는 우선한 AI 번역본
   -  `*-CHT` : `Complex` 버전과 추출한 인게임 용어집+대사집을 기반으로 중문만 참조 또는 우선한 AI 번역본
2. **게임 폴더에서 원본 파일 바꾸기**
   - 게임 설치 폴더 안의 `OPUS Echo of Starsong_Data` 폴더로 들어갑니다.
     (Steam → 게임 우클릭 → *관리 → 로컬 파일 보기*로 열 수 있습니다.)
   - 그 안의 `sharedassets2.assets` 파일을 찾습니다.
   - **원본은 지우지 말고**, 이름 뒤에 `.bak`를 붙여(예: `sharedassets2.assets.bak`) 따로 백업해 둡니다. 나중에 되돌리고 싶을 때 이 백업을 원래 이름으로 되돌리면 됩니다.
   - 받아 둔 패치용 `sharedassets2.assets`를 이 폴더에 붙여넣어 덮어씁니다.
3. **게임 실행 → 설정(Settings) → 언어에서 한국어 선택.**

> 게임이 만약 업데이트되면 이 파일이 새로 덮여 한국어가 사라질 수 있습니다. 그럴 땐 최신 패치 파일을 다시 받아 2번 과정을 반복하면 됩니다.

  - 용맥 초화 -> 용맥 화초
  - 산괴 백경 -> 군산백
  - 용맥의 잔향 -> 별노래의 메아리

## 3. 어떤 마음으로 번역했나 (번역 의도)

단순 기계 번역이나 한쪽 언어만 보고 옮긴 게 아닙니다. 이 게임은 언어판마다 이름과 뉘앙스가 꽤 다릅니다. 그래서 번역기와 사전, AI의 도움을 받되 **세 판본을 겹쳐 보고** 가장 원작에 충실한 우리말을 골랐습니다.

- **뜻(무슨 말인지)** — 공식 **영어판**을 기준으로 삼았습니다.
- **문체·말맛·격식, 그리고 한자에서 온 고유명** — **중국어 원작(번체)**을 기준으로 삼았습니다. 영어판은 종종 캐릭터와 캐릭터 간의 격식이나 함축을 밋밋하게 만들고 스토리 떡밥과 관련한 많은 요소가 단어 부재의 이슈로 오역되어 제대로 전달되지 않아 재미를 반감할 것이라고 생각했습니다.
- **미묘한 뉘앙스** — **일본어판**을 곁눈질로 참고했습니다.

그 위에 두 가지 원칙을 얹었습니다.

- **번역투를 걷어내고 자연스러운 한국어로** 직역해서 어색한 말("~을 가지고 있다", "폭발에 의해")은 우리가 실제로 쓰는 말("~이 있다", "폭발로")로 보이는 대로 다듬었습니다.
- **인물의 성격과 말투를 살려서** 누가 누구에게 말하느냐에 따라 반말·존댓말·호칭을 다르게 정했습니다(아래 3-3 참고).

### 3-1. 이름은 어떻게 정했나

- **사람 이름은 공식 영어 이름을 따릅니다.** 영어판 공식 아트북을 참고하고, 일어 버전도 약간 고려하여  적었습니다. → **에다, 레미, 케이, 본즈, 레드, 러셀 박사, 라마**.
- **단, 주인공 이(李)씨 가문만 예외로 한국식.** 주인공은 이미 한국 팬 사이에서(그리고 공식 아트북에서도) **"이준"**으로 알려져 있어 그대로 살렸고(중문에선 이모? 이막?), 그 가족도 같은 방식으로 **"이현"**(종손)이라 했습니다(공식에선 Shen Lee로, 중문 한자 표기 찾아서 치환).
- **신·신화에 나오는 이름은 한자음 그대로.** 영어판이 서양 신 이름(Helius, Phoenix 등)으로 바꿔 놓았어도, 세계관의 한자 이름 체계를 지키려고 우리 한자음으로 통일했습니다. → **을황, 태을, 후토, 촉룡, 흑룡, 백룡, 만도**.
- **한자 뒤에 숨은 서양 지명은 발음대로.** 중국어판은 서양 이름도 한자로 소리만 빌려 적는데, 이런 건 원래 발음을 살렸습니다. → **메이페어, 에펠, 마르세유, 보헤미아**.

### 3-2. 알아 두면 좋은 핵심 단어

이 게임을 이해하는 열쇠가 되는 몇 단어입니다.

| 우리말 | 원어 | 왜 이렇게 옮겼나 |
|---|---|---|
| **별노래** | 龍鳴 / Starsong | 게임의 중심 테마. |
| **별노래의 메아리** | 게임 제목 | 한국에 알려진 공식 제목 표기를 그대로 씁니다. |
| **용맥** | 龍脈 / Lumen | 우주에 흐르는 세계관의 핵심 에너지 지맥. |
| **영(靈)** | 汜(사) | "사람이 떠나면 이것이 되어 빛의 바다에 녹아든다"는 설정의 물질. 혼이 깃드는 매질이라, *메아리*라는 제목과 공명하도록 **영(靈)**으로 정했습니다. 본래는 흐르는 지류의 의미로 쓰인 것같으나, 일어는 이치로 번역했고, 영어는 빛으로 번역한걸 보고 언급되는 번역된 대사에 맞춰 제 이해대로 적절히 붙였습니다.|
| **흑룡** | 黑龍 / Banshee | 이야기의 중심이 되는 혜성. 영어권은 동양의 용에 익숙치 않아 유럽신화와 라틴권 요소로 치환했지만 용맥·별노래와 같은 '용(龍)' 계열로 묶기 위해 한자음으로 통일했습니다. |
| **만도** | 萬道 / Myria | 고대 문명의 이름. ("미리안"으로 표기했다가 이 표기는 영어에서만 쓰기에 통일성을 위해 만도로 결정했습니다) |

> 왜 "동해(East Ocean)"가 아니라 "영해"인지, 왜 "밴시"가 아니라 "흑룡"인지 같은 낱낱의 근거가 궁금하다면 → `Trans-Complex2KR/decisions/localization_decisions.md`에 결정마다 이유가 적혀 있습니다.

### 3-3. 인물마다 말투가 다릅니다

한국어는 누가 누구에게 말하느냐로 말투가 갈립니다. 게임 대사 4,700여 줄을 중문/일어 양쪽으로 분석해 인물별 말투와 호칭을 정했습니다. 예를 들면:

- **에다**는 툭툭 던지는 반말에 냉소적 유머 — 겉은 시니컬하지만 속은 따뜻하게.
- **준**은 친구에겐 부드러운 반말, 어른·상급자에겐 또렷한 존댓말 — 예의 바르고 겸손하게.
- **레미**는 에다를 **"언니"**라 부르는, 애교와 가시가 섞인 활기찬 반말.
- **케이**는 준을 **"도련님"**이라 부르며 지키는 우직한 호위.
- **홍루(선박 AI)**는 감정 없는 정중한 합쇼체.

> 인물별 성격·말투·호칭의 상세 기준은 → `Trans-Complex2KR/characters/character_profiles.md`.

## 4. 저장소 폴더 안내

| 폴더 | 무엇이 들었나 |
|---|---|
| **Trans-Complex2KR/** | **이번 번역의 본체.** 중국어·일본어·영어를 복합 판단해 옮겼다는 뜻에서 `Complex`. 최종 번역문과 모든 결정·용어집·인물 설정이 여기 있습니다. |
| **Common/** | 언어와 무관한 공통 자료. 게임 파일 구조, 폰트 만드는 법, 번역을 게임에 넣는(주입) 방법 등 기술 문서입니다. |
| **Origin/** | 손대지 않은 게임 원본 데이터(대조·복구용). |
| **Trans-CHT2KR/**, **Trans-EN2KR/** | 나름 고민하고 차용했지만 그 번역이 마음에 들지 않을 수 있어 특정 한 언어(중국어만 / 영어만)를 기준으로 재작성한 별도 번역을 만들고자 위한 자리입니다. 나중에는 셋 중 하나를 골라 쓰시면 됩니다.|

`Trans-Complex2KR/` 안을 좀 더 들여다보면(단, 스포 가능성이 있으니 가급적 자제):

- `decisions/` — 모든 번역 판단과 그 근거를 적은 결정 기록.
- `glossary/` — 세계관 용어·지명·인물·세력 등 **용어 사전**(번역 일관성의 기준).
- `characters/` — 인물의 성격·말투·호칭 기준서와, 대사별 화자 매핑.
- `translations/` — 최종 한국어 번역 전량(`*_kr.json`).
- `build/` — 이 번역을 실제 게임 파일로 만든 결과물이 있던 자리(실수;; 근데 귀찬은..)

## 5. 직접 다시 빌드하려면 (개발자용)

번역을 고쳤거나 게임이 업데이트되어 패치 파일을 새로 만들어야 할 때 사용합니다. Python이 필요합니다.

```bash
python build_assets.py Complex2KR      # 이 번역으로 패치 파일 생성
python build_assets.py --all           # 번역이 준비된 모든 Trans-* 빌드
python build_assets.py --list          # 빌드 가능한 프로젝트 목록
```

`build/sharedassets2.assets`가 만들어지며, 이 파일이 곧 1번에서 게임 폴더에 덮어쓰는 패치 파일입니다. 주입 절차의 함정·주의사항은 `Common/injection-guide.md`에 정리돼 있습니다.

## 6. 저작권과 고지

- 이 저장소는 **번역 텍스트와 작업 기록만** 담습니다. 게임 원본 데이터나 재배포 불가능한 폰트가 통째로 들어간 파일은 저작권 문제로 배포하지 않습니다.
- 완성된 패치 파일은 게임 원본 파일을 기반으로 만들어지므로, **정품 게임을 소유한 사용자가 본인 게임에 적용**하는 용도로만 사용해 주세요.
- 게임 공식 크레딧은 번역없이 원문 그대로 두었고(다른 언어 버전과 통일), 비공식 크레딧은 게임 내 크레딧 최하단에 공식과 구분해 표기했습니다.
